# Vaults 2.1 Update — Implementation Plan

## Goal
Ship Vaults **2.1** on the `Alpha` branch: sharing management (with revoke), admin/console
commands, bStats metrics, and four concrete 2.0 bug fixes. Scope confirmed with the user.

## Current state (verified in code)
- Paper/Folia plugin. Java 21, Gradle + `shadowJar`, `paper-api:1.21.11-R0.1-SNAPSHOT`.
- Files:
  - `Vaults.java` — main class + `Listener` + `/vault` `CommandExecutor`/`TabCompleter`. Holds
    session cache, async load/save, nav buttons, sharing.
  - `DatabaseManager.java` — SQLite (`vault_pages`, `vault_shares`, `meta`), versioned migrations
    via `PRAGMA user_version`, append-only `MIGRATIONS` list.
  - `ConfigMigrator.java` — `CURRENT_CONFIG_VERSION = 1`, `config-version` marker, merges new keys.
  - `UpdateChecker.java` — Modrinth checker (out of scope for 2.1).
- Sharing is **whole-vault**, direction owner → guest (`vault_shares.owner_uuid`, `guest_uuid`).
  `/vault share <player>` requires the target online; `/vault shared` lists owners who shared with
  you. **No revoke exists.**
- Nav buttons placed at `size-1` (next) and `size-9` (prev), left **null** when there is no such page.
- bStats (`org.bstats:bstats-bukkit:3.1.0`) is bundled and relocated in `build.gradle` but **never
  initialized**.

## Locked decisions
1. **Split command surface.**
   - `/vault` (players): `""` → own vault p1; `<player>` → open allowed/shared vault;
     `share <player>`; `unshare <player>`; `shared` (who shared with me).
   - `/vaultadmin` (op/console, alias `va`, single perm `vaults.admin`): `open <player> [page]`,
     `shares <player>`, `unshare <owner> <guest>`, `clear <player> <page|all> [confirm]`, `reload`,
     `info <player>`.
2. Shares resolve **offline players by name** (async `Bukkit.getOfflinePlayer`), stored by UUID.
3. Shares stay **whole-vault** — no `vault_shares` schema change.
4. bStats **plugin id = 29399**.
5. `clear ... all` requires a literal `confirm` argument; single-page clear does not.
6. One permission node **`vaults.admin`** (default op) gates all of `/vaultadmin`.
7. Bug fixes in scope: (a) nav-slot reservation bypass, (b) revoked-share navigation re-check,
   (c) `api-version`/version alignment, (d) self-share + duplicate feedback.
   Update-checker slug/URL change was **declined** — leave as-is.

## Work items (ordered)

### 1. Version + manifest
- `build.gradle`: `version = '2.1'`.
- `plugin.yml`: `api-version: '1.21.11'`.
- `plugin.yml`: update `vaults.admin` description; add command block:
  ```yaml
  vaultadmin:
    description: Manage Vaults
    aliases: [va]
    usage: /vaultadmin <open|shares|unshare|clear|reload|info> ...
    permission: vaults.admin
  ```

### 2. DatabaseManager additions (no schema change)
Add under the existing `lock`, logging on `SQLException`:
- `boolean removeShare(UUID owner, UUID guest)` — `DELETE ... WHERE owner_uuid=? AND guest_uuid=?`, return affected > 0.
- `List<UUID> guestsOf(UUID owner)` — reverse of `ownersSharingWith`.
- `void deletePage(UUID owner, int page)`.
- `int deleteAllPages(UUID owner)` — returns rows deleted.
- `int pageCount(UUID owner)` and `long totalBytes(UUID owner)` for `info`
  (`SELECT COUNT(*), COALESCE(SUM(LENGTH(data)),0) FROM vault_pages WHERE owner_uuid=?`).

### 3. Sharing commands (`Vaults.java`)
- `share <player>`: async resolve target via `Bukkit.getOfflinePlayer(name)`; if
  `!hasPlayedBefore()` → `player-offline`; self → `share-self`; already shared → `share-already`;
  else `addShare` → existing `vault-shared`.
- `unshare <player>`: async resolve; if not shared → `unshare-none`; else `removeShare` → `vault-unshared`.
- `shared`: unchanged.
- Tab completion: keep `share|unshare|shared`; for `share`/`unshare` complete online names as arg 2.

### 4. Navigation permission re-check (bug fix)
- New helper `openVaultChecked(Player p, int page, UUID ownerUUID)`:
  - owner, op, or `vaults.admin` → `openVault` directly (owner check avoids a DB hit).
  - else async `db.isSharedWith(ownerUUID, p.getUniqueId())`; if allowed `runOnPlayer(openVault)`,
    otherwise `runOnPlayer` → close inventory + `no-permission`.
- Use it in `onInvClick` nav branch (replacing the direct `openVault` call), for `/vault <player>`,
  and for `/vaultadmin open`.

### 5. Nav-slot reservation (bug fix)
- In `openSession`, **always occupy both** reserved slots:
  - `size-1`: nav-next arrow if `page < totalPages`, else a nav-tagged filler.
  - `size-9`: nav-prev arrow if `page > 1`, else a nav-tagged filler.
- Filler = `GRAY_STAINED_GLASS_PANE` (or `BLACK_STAINED_GLASS_PANE`) with `navKey` PDC tag
  `"filler"`, so `isNavItem` is true → filtered from `snapshot()`/load and clicks are cancelled.
  This blocks shift-click/hotbar from filling empty reserved slots and the later overwrite/loss.

### 6. `/vaultadmin`
- New class `AdminCommand implements CommandExecutor, TabCompleter`, built with the `Vaults` ref;
  register in `onEnable`. Expose package-private helpers from `Vaults`: `openVaultChecked`, `msg`,
  `rawMsg`, `db()` accessor.
- Subcommands:
  - `open <player> [page]` — sender must be a `Player`; clamp page to `[1,total-pages]`.
  - `shares <player>` — console-ok; header + `guestsOf` (shared with) + `ownersSharingWith` (shared to them), else `admin-shares-none`.
  - `unshare <owner> <guest>` — console-ok; resolve both; report `admin-unshared` / `admin-unshare-none`.
  - `clear <player> <page|all> [confirm]` — console-ok; page → `deletePage` + `admin-cleared`;
    `all` without `confirm` → `admin-clear-confirm`; `all confirm` → `deleteAllPages` + `admin-cleared`.
  - `reload` — `reloadConfig(); saveDefaultConfig(); getConfig().options().copyDefaults(true); ConfigMigrator.migrate(this);` then reply `admin-reloaded`.
  - `info <player>` — pages used, storage size (KB), share counts.
- Tab completion: subcommand list → player names → `confirm` for clear-all.

### 7. bStats
- Private `initMetrics()` called at end of `onEnable`, wrapped in try/catch (log warning; never
  disable the plugin): `new Metrics(this, 29399)` from `org.bstats.bukkit.Metrics` (already bundled).
- Optional single `SimplePie` for configured `vault-settings.total-pages`. No plugin-side toggle
  (bStats has its own opt-out config).

### 8. Config schema bump + messages
- `ConfigMigrator`: `CURRENT_CONFIG_VERSION = 2`; add empty `case 1 -> { }` (existing merge loop adds new keys).
- `config.yml`: `config-version: 2`; add message keys:
  `vault-unshared`, `share-already`, `share-self`, `unshare-none`,
  `admin-opened`, `admin-shares-header`, `admin-shares-owners`, `admin-shares-guests`,
  `admin-shares-none`, `admin-unshared`, `admin-unshare-none`, `admin-cleared`,
  `admin-clear-confirm`, `admin-reloaded`, `admin-info` lines, `admin-usage`.
- **Do not rename** existing keys.

### 9. Build & verify
- `./gradlew build` (runs `shadowJar`) succeeds on Java 21.
- `./gradlew runServer` smoke test, or load the jar on a Paper 1.21.11 test server.

## Validation checklist
- `/vault` opens own vault; next/prev navigation works page 1 ⇄ 2.
- Shift-click and hotbar-swap cannot place items into the reserved slots; content survives reopen.
- Revoked-share navigation: A opens B's shared vault, B runs `/vault unshare A`, A clicks Next →
  inventory closes with `no-permission`.
- `/vault share <offline>` succeeds; self-share blocked; duplicate shows `share-already`;
  `/vault unshare` revokes; `/vault shared` reflects changes.
- `/vaultadmin` from console works for `shares`/`unshare`/`clear`/`reload`/`info`; `open` requires a player.
- `clear <player> all` without `confirm` is refused; with `confirm` wipes.
- Existing 2.0 `config.yml` gains v2 keys, custom values preserved, `config-version: 2`.
- bStats id 29399 initializes with no warning and submits.
- All inventory/db work routed through `runOnMain` / `runOnPlayer` / async executor (Folia-safe).

## Risks / notes
- `Bukkit.getOfflinePlayer(name)` can block — always call it off the main thread.
- Nav re-check adds one async round-trip per page turn; guard with `player.isOnline()`.
- No new DB migration expected: verify `PRAGMA user_version` stays `1` after the change.
- Update-checker slug/URL intentionally unchanged (out of scope).

## Out of scope
Per-page shares, per-rank page counts, console `/vault` execution, economy, update-checker slug change.
